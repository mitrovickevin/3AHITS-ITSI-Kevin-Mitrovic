## 1. Kali Linux & Metasploitable installieren
-  Kali Linux und Metasploitable von dem USB - Stick, ***kopieren*** auf dem Desktop.

- Dann einen Ordner erstellen in Dokumente namens ***Virtual Machines*** oder was ähnliches. 

- Die kopierten ZIP Dateien in den Ordner Virtual Machines ***extrahieren***.

- Öffne VMware Workstation player und klick auf ***Open a Virtual Machine***. 

- Navigiere nun zu Kali Linux oder Metasploitable so tief, bis die `.vmx Datei` auftaucht. Dann links klick und öffnen.

- Mache das nun bei `beide`

- Nun sind beide Startklar und kannst beide öffnen mit dem ***grünen play Button***.

<br>
<br>

## 2. VSCode installieren
- Username: ***kali***
- Passwort: ***kali***

- Öffne in Kali Linux dein ***Terminal***

- Um deine Tastatur auf ein Deutsches Layout zu wechseln benötigst du den Befehl `setxkbmap de`.

- Danach mit den Befehlen installieren 
`wget -O vscode.deb "https://code.visualstudio.com/sha/download?build=stable&os=linux-deb-x64"` & `sudo apt install ./vscode.deb`.

- Dann `code --version`

- Um VSCode zu öffnen gebe den Befehl `code .` ein.

<br>
<br>

## 3. VSCode mit Git verbinden 
- Gebe die 3 Befehle im Terminal ein.

- `git config --global user.name "Jon Doe"` ***(User name eingeben)***

- `git config --global user.email "deine@email.at"` ***(Email von Git)***

- `git clone <GitHub Repo Link>` ***(zwischen den <> Link von Github reinkopieren)***
